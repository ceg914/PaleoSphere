## 단계별 완료 기준

| 단계 | 완료 기준 | 상태 |
|---|---|---|
| Phase 0 | 새 PC에서 문서만 보고 환경 구성, 빈 EXE 실행 | 🟡 문서·빌드·내보내기는 됨. Windows에서의 실행은 미확인 |
| Phase 1 | 배치한 생물이 스스로 먹고 마시며 에너지가 변하고, 종료 후 복구 가능 | ✅ (Linux에서 확인) |
| Phase 2 | 먹이·물 부족이 개체 수에 영향을 미치고 그래프와 사건 로그에 반영 | ✅ (Linux에서 확인) 아사·탈수·포식이 개체군 그래프, 사망 원인 탭, 이벤트 탭에 나타남. 육식동물 1종, 도주·포식·사망·자원 환원 구현 |
| Phase 3 이후 | — | ⬜ |

**Windows 실행 확인은 아직 남아 있습니다.** 기획서 규칙대로라면 Phase 0의 이 항목을 먼저 마쳐야 하지만, 개발 환경에 Windows가 없어 사용자의 진행 요청에 따라 Phase 2를 먼저 진행했습니다. Windows CI 러너에서 자동 테스트(기준 해시 포함)는 통과합니다.
