# 게임 설계 요약

전체 기획은 [PLAN.md](PLAN.md)에 있습니다. 이 문서는 지금 버전에서 사용자가 할 수 있는 일을 요약합니다.

## 무엇을 하는 프로그램인가

세계를 만들고, 생물을 놓고, 지켜봅니다. 점수나 승패는 없습니다. 조건을 바꿨을 때 개체군과 식생이 어떻게 달라지는지 보는 것이 목적입니다.

## 0.2.0에서 해 볼 수 있는 것

1. **풍부한 저지대**에서 트리케라톱스 30마리가 낮에 먹고 물가로 가서 마시고 밤에 쉬는 것을 봅니다. 개체를 클릭하면 지금 그 행동을 왜 골랐는지 점수와 함께 나옵니다.
2. 한 곳에 수십 마리를 더 배치하고 그 자리의 식생 색이 옅어지는 것, 개체들이 다른 곳으로 옮겨 가는 것을 봅니다.
3. **자원 부족** 시나리오나 과밀 상태에서 평균 에너지가 떨어지고 아사가 시작되는 시점을 그래프로 봅니다.
4. 교란 도구로 무리를 흩어 보고 공포가 가라앉는 데 걸리는 시간을 봅니다.
5. 저장하고, 같은 시드로 새 세계를 만들어 초기 개체 수만 바꿔 비교합니다.
6. **포식자 유입** 시나리오에서 티라노사우루스를 클릭해 사냥감을 고르고 다가가 달려드는 과정을 따라갑니다. 사냥이 실패하면 다친 트리케라톱스가 달아나고, 성공하면 사체가 남아 며칠에 걸쳐 먹히고 분해됩니다.
7. 같은 시드로 포식자 수만 바꿔(0, 2, 4마리) 초식동물이 줄어드는 속도와 사망 원인 비율을 비교합니다.

## 원칙

1. 시뮬레이션과 화면을 나눈다. 프레임률이 달라도 결과가 같다.
2. 화석으로 확인된 것, 학술적 추정, 게임적 단순화를 데이터와 화면에서 구분한다.
3. 같은 시드·설정·버전이면 같은 결과가 나온다.
4. 작은 수직 슬라이스부터 만든다.
5. 에셋의 라이선스를 기록하고, 확인되지 않은 것은 넣지 않는다.
